Overview

EdgeGuard is the main embedded AI project. The Colibry board and its NPU/SDK work are part of the same project, providing the hardware acceleration and embedded deployment platform.

Objective

Build a practical edge-AI vision pipeline that can perform object detection close to the camera instead of depending on a cloud inference service.

Technologies

Engineering Pipeline

Current Implementation

The project currently includes the Colibry/NPU environment work, AIDGE setup, ONNX model loading and inference validation. Performance benchmarking and the complete real-time detection pipeline are still being developed.

Challenges & Solutions

The work includes embedded SDK setup, model import, inference validation, preprocessing/postprocessing and hardware-specific optimization.
