A complete gesture-recognition pipeline covering dataset collection, model training, camera inference and Raspberry Pi deployment.

Objective

Recognize a defined set of hand gestures from live camera input using a lightweight computer-vision and CNN pipeline suitable for edge deployment.

Current Implementation

The project covers dataset collection, image preprocessing, CNN-based recognition and camera inference. The current gesture set includes Fist, OK, Palm, Peace and Thumb Up.

Challenges & Solutions

Camera selection, real-time inference and reliable gesture classification were handled while keeping the system suitable for edge hardware.
