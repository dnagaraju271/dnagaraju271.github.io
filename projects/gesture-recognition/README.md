# Gesture Recognition CNN

Real-time hand gesture recognition using computer vision and deep learning.

## Pipeline

Camera → OpenCV / MediaPipe → preprocessing → CNN → gesture prediction → dashboard

## Gestures

- Fist
- OK
- Palm
- Peace
- Thumb Up

## Technologies

- Python
- OpenCV
- MediaPipe
- CNN
- TensorFlow / TensorFlow Lite
- Raspberry Pi
